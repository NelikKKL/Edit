# edit

Быстрый, современный текстовый редактор на Rust (аналог Блокнота), с
подсветкой синтаксиса, вкладками, деревом файлов, автозакрытием скобок и
темами на CSS-переменных.

## ⚠️ Важно про сборку

Этот проект написан «руками», без возможности локально скомпилировать его в
среде, где я его создавал (нет доступа в интернет, а значит нет доступа к
crates.io). Код написан внимательно и опирается на реальные, стабильные API
`egui`/`eframe` 0.28, но **первая настоящая проверка компиляции произойдёт в
GitHub Actions** (у него есть доступ в сеть для скачивания зависимостей).

Если сборка на GitHub упадёт с ошибкой — это, скорее всего, точечное
несоответствие версии API в 1-2 местах (комментарии в коде отмечают самые
"рискованные" места: `src/app.rs` — работа с курсором/скроллом текстового
поля). Пришлите мне лог ошибки — поправить одну-две сигнатуры займёт минуту.

## Возможности

- 📑 Вкладки, открытие/сохранение файлов любого текстового формата
- 🔢 Нумерация строк
- 🎨 Темы: светлая, тёмная, **Char** (#211F24), и своя — через CSS-файл
- ⚙ Настройки в отдельном окне (Внешний вид / Шрифт / Редактор / Дополнительно)
- 🔍 Поиск по тексту во всплывающем окне (стилизуется темой), подсветка всех совпадений
- 🖼 Кастомный заголовок окна, подстраивается под тему, поддержка полноэкранного режима
- 🌈 Подсветка синтаксиса (через `syntect`, десятки языков из коробки)
- 🧩 Автозакрытие скобок/кавычек: `(`, `[`, `{`, `"`, `'`, `` ` ``
- 🗂 Кнопка «Папка» → дерево файлов слева → клик открывает файл на редактирование
- 🔤 Выбор системного шрифта (сканирует системные каталоги шрифтов)
- 🪟 Без консольного окна при запуске на Windows (release-сборка)
- 📦 Готовые сборки: `.exe`/установщик для Windows 10/11, `.deb` для Ubuntu — собираются автоматически через GitHub Actions

## Структура проекта

```
edit-editor/
├── Cargo.toml            # зависимости + метаданные для cargo-deb
├── build.rs               # встраивает .ico в edit.exe на Windows
├── assets/
│   ├── icon.ico            # иконка Windows (мульти-разрешение)
│   └── icon.png            # иконка окна/Linux (256px), из вашего рисунка
├── src/
│   ├── main.rs             # точка входа, without console на Windows
│   ├── app.rs              # вся раскладка: заголовок, тулбар, вкладки, редактор
│   ├── theme.rs             # палитры: Light / Dark / Char
│   ├── custom_css.rs        # парсер CSS-переменных для своей темы
│   ├── settings.rs          # настройки, сохраняются в JSON
│   ├── syntax_highlight.rs  # подсветка синтаксиса (syntect) + подсветка поиска
│   ├── fonts.rs             # сканирование системных шрифтов
│   ├── file_tree.rs         # дерево файлов в сайдбаре
│   ├── search.rs             # состояние окна поиска
│   ├── editor_tab.rs         # одна открытая вкладка/файл
│   └── autoclose.rs          # автозакрытие скобок (без завязки на курсор egui)
├── installer/setup.iss     # Inno Setup: установщик Windows + регистрация типов файлов
├── linux/edit.desktop       # ярлык приложения для Ubuntu/GNOME
└── .github/workflows/build.yml  # CI: собирает .exe, установщик и .deb
```

## Сборка локально

Нужен Rust (`rustup.rs`).

```bash
cargo build --release
# бинарник: target/release/edit (или edit.exe на Windows)
```

### Linux .deb

```bash
cargo install cargo-deb
cargo deb
# результат: target/debian/edit_0.1.0_amd64.deb
```

### Windows-установщик (регистрирует «edit» в «Открыть с помощью»)

Нужен [Inno Setup](https://jrsoftware.org/isinfo.php). После `cargo build --release`:

```
ISCC.exe installer\setup.iss
```

## Сборка через GitHub Actions (рекомендуется)

1. Создайте репозиторий на GitHub и запушьте туда содержимое этой папки.
2. Actions запустятся автоматически (или вручную — вкладка Actions → Build → Run workflow).
3. Через пару минут в разделе **Artifacts** появятся:
   - `edit-windows-exe` — просто `edit.exe`
   - `edit-windows-installer` — установщик с регистрацией типов файлов
   - `edit-linux-deb` — `.deb` для Ubuntu
4. Если запушить тег `vX.Y.Z` — эти файлы автоматически прикрепятся к GitHub Release.

## Ассоциация с файлами

- **Windows**: после установки через `setup.iss`, `edit` появится в списке
  «Открыть с помощью» для файлов `.txt`, `.md`, `.json`, `.rs`, `.py` и др.
  Чтобы сделать его редактором по умолчанию — правый клик по файлу →
  «Открыть с помощью» → выбрать `edit` → «Всегда использовать это приложение».
  (Полный захват дефолтных ассоциаций Windows 10/11 требует подтверждения
  пользователя через системный диалог — так решил сам Microsoft, обойти это
  программно нельзя, это касается вообще всех сторонних редакторов.)
- **Linux (Ubuntu)**: `.deb` ставит `edit.desktop` с MIME-типами; после
  установки можно выбрать edit через «Открыть с помощью» → «Установить как
  умолчание».
- Также `edit` принимает путь к файлу как аргумент командной строки
  (`edit file.txt`), так что и ручная ассоциация тоже работает.

## Своя тема (CSS)

Настройки → Дополнительно → «Создать пример theme.css», либо создайте файл
самостоятельно:

```css
:root {
  --bg: #1e1e1e;
  --panel-bg: #252526;
  --titlebar-bg: #232121;
  --titlebar-fg: #e4e4e6;
  --sidebar-bg: #212122;
  --editor-bg: #1e1e1e;
  --fg: #d4d4d6;
  --fg-dim: #8a8a8f;
  --accent: #569cd6;
  --line-number: #5a5a5e;
  --selection: #264f78;
  --border: #333335;

  --font-family: Consolas;
  --font-size: 14;
}
```

Укажите путь к файлу в Настройках → Дополнительно, выберите тему «Своя (CSS)».
